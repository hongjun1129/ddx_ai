# 흉통 감별 EMR 사이드카 (간소화 도구)

EMR 화면 옆에 작은 창으로 띄워 쓰는 **흉통 감별진단 보조 도구**입니다.
의사 자유 서술을 AI로 인식해 명시된 임상 사실만 추출하고, 위험 감별·일반 감별을
한 화면에 보여줍니다. 최종 진단·처치 판단은 의료진이 우선합니다.

> ⚠️ **임상 의사결정 보조 도구입니다.** 진단기나 EMR을 대체하지 않으며, 모든 AI 추출
> 결과는 의사 확인을 거친 뒤에만 반영됩니다. 임상 적용 전 원문 가이드라인 확인이 필요합니다.

## 바로 사용

`흉통_EMR_보조도구_간소화.html` 파일 하나로 완결된 단일 HTML 앱입니다.
브라우저로 열면 바로 동작합니다(별도 서버·빌드 불필요).

AI 서술 인식을 쓰려면 우측 상단 ⚙ 설정에서 제공자(OpenAI / Claude)와
API 키(직접 연결) 또는 병원 프록시 URL을 지정합니다. 키는 브라우저 세션 메모리에만
유지되고 파일에 저장되지 않습니다.

## 주요 기능

- **의사 자유 입력 → AI 서술 인식** (OpenAI / Claude 선택, 구조화 출력 + 의사 확인 모달)
- **위험 감별 7 · 일반 감별 7** 나란히 표시, 제목 클릭 시 전체 90개 목록
- **KCD-8 질병분류기호** 90개 질환 매핑(상세창 표시)
- **위험 감별 18개**의 진단기준·검사·배제 포인트를 **국내 진료 가이드라인에 맞춰 정렬**
- **확정 진단란 + 진료 요약 생성** (확정 진단·미배제 red flag·추가 확인·배제 감별 종합)
- 전체 목록에서 **× 빠른 배제**, 질환명 **더블클릭 → 확정 진단 추가**
- 국내 EMR(의사랑 계열)과 위화감 없는 클래식 Windows UI(굴림체·회색 베벨·남색 타이틀)

## 재빌드 (선택)

최종 HTML은 아래 소스에서 결정적으로 생성됩니다.

```bash
cd emr-sidecar
node src/build.cjs
```

`src/build.cjs`는 다음을 결합합니다.

| 파일 | 역할 |
|---|---|
| `src/흉통_EMR_보조도구.html` | 원본 — 임상 데이터셋(질환 90 / 체크리스트 1,431) + SidecarCore 로직 |
| `src/part_top.html` | UI 셸(HTML/CSS) |
| `src/part_app.html` | 앱 로직(JS) |
| `src/kcd_slim.json` | 검증된 KCD-8 코드맵(90개) |
| `src/dx_patch.json` | 국내 가이드라인 정렬 패치(위험 감별 18개 필드) |

→ 루트에 `흉통_EMR_보조도구_간소화.html` 생성.

## 가이드라인 검토 자료

`가이드라인_검토.html` — 위험 감별 18개를 최신 가이드라인과 대조한 검토 목록
(확정 59 · 과장 8 · 해결 2). 무엇이 왜 바뀌었는지 추적·검토용입니다.

참조 가이드라인: 대한심장학회·대한내과학회 급성관동맥증후군 지침, 대한흉부심장혈관외과학회
(2022 ACC/AHA 대동맥 준용), 대한결핵및호흡기학회·대한혈전지혈학회(2019 ESC PE),
대한외상학회 KAST/KTAS(ATLS 10th), Tokyo Guidelines 2018 등.
국내 전용 지침이 있으면 이를, 국제 지침을 채택한 영역은 "국내 채택/준용"으로 표기.
